# UniSpend — Student Budget Management App

UniSpend is a student-focused budget management application built with Python and Streamlit. It helps students manage their finances, track daily spending, plan monthly budgets, and monitor savings goals through a simple and user-friendly dashboard.

## Features

- **Income & Expense Tracking** — Record and manage income and expenses.
- **Expense Categories** — Organize transactions into categories.
- **Monthly Budget Management** — Set monthly budgets and monitor spending.
- **Savings Goals** — Create and track personal savings goals.
- **Spending Analytics** — Visualize financial data and spending patterns through interactive charts.
- **CSV Export** — Export transaction data for further analysis.
- **Transaction Management** — Filter and edit transactions.

## Technology Stack

- **Language:** Python
- **Web Framework:** Streamlit
- **Database:** SQLite
- **Data Analysis:** Pandas
- **Data Visualization:** Plotly

## Getting Started

### Prerequisites

- Python 3.10 or later
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Imasha-Vithana/UniSpend.git
   ```

2. Navigate to the project directory:

   ```bash
   cd UniSpend
   ```

3. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

4. Activate the virtual environment on Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

5. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Run the application:

   ```bash
   streamlit run app.py
   ```
